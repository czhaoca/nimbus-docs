Slack bot commands

## Commands

### run

Start the Slack bot over Socket Mode (blocking).

Usage: `nimbus-admin slack run [OPTIONS]`

| Flag | Type | Required | Default | Help |
| --- | --- | --- | --- | --- |
| `--credential` | text | no | - | Bot token (or set SLACK_BOT_TOKEN env) |
