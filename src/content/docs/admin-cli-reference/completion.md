Generate shell completion scripts.

## Commands

### bash

Output bash completion script.

Usage: `nimbus-admin completion bash [OPTIONS]`

_No options._

### fish

Output fish completion script.

Usage: `nimbus-admin completion fish [OPTIONS]`

_No options._

### zsh

Output zsh completion script.

Usage: `nimbus-admin completion zsh [OPTIONS]`

_No options._
