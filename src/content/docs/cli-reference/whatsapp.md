Nimbus WhatsApp bot management.

## Commands

### run

Start a lightweight server for the WhatsApp webhook.

Usage: `nimbus whatsapp run [OPTIONS]`

| Flag | Type | Required | Default | Help |
| --- | --- | --- | --- | --- |
| `--host` | text | no | `0.0.0.0` | Bind address |
| `--port` | integer | no | `8001` | Bind port |
